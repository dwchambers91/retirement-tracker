# Retirement Savings Goal Tracker

A full-stack web application for setting retirement savings goals and
projecting progress over time.

## Tech stack (planned)

- Front end: Angular, TypeScript
- Back end: Java, Spring Boot RESTful microservices
- Database: PostgreSQL
- Testing: JUnit, Mockito, Jasmine, Selenium
- Cloud and CI/CD: AWS, automated build and deploy pipeline

## Status

In development.
